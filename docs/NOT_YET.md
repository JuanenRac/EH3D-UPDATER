# EH3D-UPDATER: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Signed commits by default | Most revisions of the suite are not signed yet, so a required signature would refuse almost every update | the suite signs its commits and the owner decides to require it |
| Update of the workshop CM5 with this tool | The CM5 is updated by releases with the deploy script of the server, not by git | the workshop adopts one update path for both |
| Background updates | An update replaces files and runs a build script, so it needs a person who confirms it | never planned without a confirmation |
| Publication on PyPI | The tool is used from this repository by the people who develop the suite | the suite has users who do not clone it |
| A real end-to-end run with the real GitHub | It needs a project that is published and a person who accepts the install | an EH3D project is released and the owner runs it |
